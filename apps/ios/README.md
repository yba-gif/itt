# ITT-Rehber iOS app

SwiftUI app, iOS 16+. Project files are generated by [XcodeGen](https://github.com/yonki/XcodeGen).

## Build

```bash
brew install xcodegen
cd apps/ios
xcodegen generate
open ITTRehber.xcodeproj
```

Run on **iPhone 15** simulator (iOS 17). The app expects the backend at
`http://localhost:8000` — make sure `docker compose up -d` has the backend healthy
in another terminal.

## Phase 1 scope (this scaffold)

- Tab bar: Rehber / Etkinlikler / Bilgi / Profil
- Sağlık directory: list view (kanton + free-text filter) + detail view
- Other 9 directories tile through to a "Yakında" placeholder
- Profil: email signup/login, Hesabımı Sil
- Submit flow for Sağlık only (status=pending, awaits admin approval)
- SwiftData offline cache for last-viewed list
- Bilgi tab: hardcoded Acil Durumlar (always offline)

## Deferred to later phases

- SIWA wired to backend `/auth/siwa` (Phase 1 has the button, Phase 2 wires it; needs a real Sign in with Apple capability + Apple Developer team ID)
- Push notifications (Phase 3)
- Payment / TWINT / invoice flows (Phase 3)
- Welcome Guide content + Events feed (Phase 2)

## Sign in with Apple

Capability requires a real Apple Developer team. Until `DEVELOPMENT_TEAM` is set in
`project.yml`, the SIWA button is a stub that surfaces a "yakında" alert.
